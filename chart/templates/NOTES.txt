Login: code-server's own password page. The password is the tenant credential
shown once at creation; reset or change it from the PaaS service page
("Admin Credentials") — saving restarts the pod. code-server reads only the
chart's read-only /etc/code-server/config.yaml (auth: password): editing
~/.config/code-server/config.yaml has no effect.

Secrets inside the IDE: the login password ($PASSWORD) and the optional keys from the
service page (ANTHROPIC_API_KEY, OPENROUTER_API_KEY, GIT_TOKEN) are environment
variables of this container. Every process here runs as the same user, so any
terminal command, extension or AI assistant (Pi, Claude Code, Codex, Omnigent sessions) can
read all of them — the password too, from /proc/1/environ, although code-server drops
it from its own children's env. Prefer a budget-limited LiteLLM virtual key (or an
OpenRouter key with a credit limit) over a master key, a fine-grained short-lived Git
token, and only trusted extensions. Suspect a leak: reset the password on the service
page (signs every browser out) and rotate the keys. README: 容器內看得到的密碼與金鑰.

Built in: Pi, Claude Code, and Codex, available from the terminal and ACP sidebar.
Sign in per agent (`pi login`, `claude auth login`, `codex login --device-auth`).
Skills share /data/pi-agent/skills. Edit shared/mcp.json under the same private
volume, run woow-agent-sync, and reconnect sessions to load MCP changes.

installs, ~/.local/bin — on PATH after the system dirs, so it never shadows the
image's claude / pi / omnigent), ~/.gitconfig and the shell history live on the pi-data volume
(/data/pi-agent/home); ~/.cache is a {{ (.Values.persistence.cache | default dict).sizeLimit | default "unlimited" }} scratch area that a pod restart empties.

service run Claude Code / pi sessions in this IDE, open the IDE terminal once and run
  omnigent login {{ include "woow.omnigentHost.serverUrl" . | default "<Omnigent URL>" }}
(WOOW default: the workspace's Omnigent admin account, which then owns this machine).
Within a minute the IDE appears in that account's machine list as
"{{ include "woow.omnigentHost.hostName" . }}" and comes back by itself after every restart;
sessions use /workspace. Status: `omnigent-host-status` in the terminal (new terminals
print it whenever you need to act). Do not start `omnigent host` yourself: it already
runs, managed automatically. The platform never holds an Omnigent token. Deleting
/data/pi-agent/omnigent/auth_tokens.json only logs this machine out locally; to revoke
the login, delete or disable the user in Omnigent.
